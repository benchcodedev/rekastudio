# Studio Reka – Architecture & Spatial Design Practice

A responsive, modern marketing landing page for **Studio Reka**, an architecture studio based in Indonesia.

## 🏛️ About
Studio Reka is an architecture practice specializing in residential, commercial, urban planning, and landmark architecture.

## 🚀 Tech Stack
- **HTML5**
- **Tailwind CSS** (CDN)
- **Vanilla JavaScript** (No build step required)
- **Responsive Web Design** (Desktop, Tablet & Mobile)

## 📁 Project Structure
```text
├── index.html        # Main landing page
├── css/
│   └── style.css     # Custom stylesheets and glassmorphism components
├── js/
│   └── main.js       # Interactive UI scripts (modal, gallery lightbox, accordions)
└── assets/
    └── images/       # High-resolution architectural photography & icons
```

## 💻 How to Run Locally
Simply open `index.html` in your browser, or start a local HTTP server:

```bash
# Using Python
python -m http.server 8089

# Using Node.js (npx serve)
npx serve .
```
